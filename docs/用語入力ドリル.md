# 用語入力ドリルの試作

短い問いから答えを思い出し、読みの一部を入力して候補の用語を選ぶ。候補を選んだ後に「解答する」で採点する。

## 今回の範囲

- 例題1問：ホルモン分泌などにみられる、約24時間周期の生体リズムを何というか。
- 正答は「概日リズム」。「がいじつ」で候補に出る。「サーカディアンリズム」も同じ正答として扱う。
- 候補は搭載済み用語集の読みと用語名から検索。入力前は候補を出さず、最大8件を表示する。表示順は文字の一致度と用語名で決め、正答を優先しない。
- 候補タップと上下キー・Enter、かな種・全角半角、IME変換、入力し直し、誤答、答えを見る、再試行に対応。
- 試作の回答は学習記録に保存しない。既存の過去問の採点・成績、ROM/MMTドリル、暗記カードは変更しない。
- 問題の一括生成、追加問題の医学的検品、学習記録への統合、公開版への反映は今回の対象外。

## 起動

リポジトリ直下で `python tools/serve.py 8791` を実行し、`http://localhost:8791/app/term-drill.html` を開く。ホームの「暗記・復習」にも入口を追加した。

## ファイル

- `app/term-drill.html`：問題・候補入力・解答後の画面。
- `app/term-drill.js`：用語集読込、読み検索、候補選択、例題採点。新しい問いは医学的根拠と正答キーを明示して追加する。
- `app/term-drill.css`：共有色トークンを使ったスマホ・PC・暗色表示。
- `app/index.html`：入口のリンクだけを追加。
- `app/sw.js`：新規3ファイルをSHELLに追加、キャッシュ版を最新スマホUIのv9からv10へ更新。
- `tools/term_input_check.cjs`：独立したブラウザーでの機能・表示検証。

既存データファイルの変更はない。試作は別worktree・ブランチ `feature/term-input-drill` で作成し、スマホUI改修コミット `7d976c4` を基点として取り込んだ。元の作業フォルダーには変更を加えていない。

## 医学的根拠

- 搭載済み `content/glossary/glossary.json` の「概日リズム」。読み、用語説明、別名（意味欄のサーカディアンリズム）を利用し、元データは変更しない。
- [NIH / NIGMS: Circadian Rhythms](https://www.nigms.nih.gov/education/fact-sheets/Pages/circadian-rhythms)：24時間周期とホルモン放出への影響を確認（2026-11-10閲覧）。出題文は資料に基づく独自の例題。

## 検証

結果は `用語入力確認/report.json` と画面画像に記録する。独立したChromeで64項目に合格。360/390/412/1280px、暗色、タップ・キーボードでの候補選択、模擬IME変換中のEnter抑止、候補の選び直し、正誤判定、別名、読込失敗、本体過去問の採点と誤り理由を確認した。

検証はローカルファイルをブラウザーのリクエストへ直接返す方式で行い、API保存も模擬応答とした。実際の学習記録は読み書きしていない。実機Androidのソフトキーボード・IME、スクリーンリーダー、実ネット配信とService Workerの圏外動作は未確認。
