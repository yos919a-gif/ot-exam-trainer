# 用語入力ドリル（3科目60問）

短い問いから答えを思い出し、読みの一部を入力して候補の用語を選ぶ。候補を選んだ後に「解答する」で採点する。

## 今回の範囲

- 解剖学・生理学・運動学を各20問、計60問。科目を1つ選ぶか、すべての科目を対象にする。
- 5問・10問・20問・すべて（単一科目20問／全科目60問）を選べる。ランダム順または問題順で出題する。
- 全科目の問題順は解剖→生理→運動と交互に並べ、短いセットでも3科目を含める。各科目の問題順はデータファイルの順。
- 短い問い・正答・許容別名・解説・一次資料を各問に明示する。問題IDと正答の一覧は `用語入力問題一覧.md` を参照。
- 「がいじつ」→「概日リズム」を選ぶ1問の例題も残した。`?demo=1` で開ける。
- 候補は搭載済み用語集の読みと用語名から検索。入力前は候補を出さず、最大8件を表示する。表示順は文字の一致度と用語名で決め、正答を優先しない。
- 候補タップと上下キー・Enter、かな種・全角半角、IME変換、入力し直し、誤答、答えを見る、再試行に対応。
- 解答後に解説と出典を表示。最終結果で正解・不正解・答えを見た数と回答一覧を表示する。不正解と答えを見た問題だけ解き直せる。
- 通常練習の回答・中断位置は `localStorage` の `ot-term-drill-v1` に保存。完了した直近30回と中断中の1回を保持し、リロード後もメニューの「前回の続きから」で再開できる。例題モードは保存しない。
- 保存不可でも練習を継続する。壊れた保存結果や正答判定と矛盾する結果は集計に使わない。
- 保存キー・記録形式・既存の生理学20問のIDは維持する。科目を変更しても中断記録は変更せず、実際に解いた科目と件数を再開案内・結果に表示する。
- 端末間の同期は対象外。既存の過去問の採点・成績・復習予定、ROM/MMTドリル、暗記カードの記録には書き込まない。

## 起動

リポジトリ直下で `python tools/serve.py 8791` を実行し、`http://localhost:8791/app/term-drill.html` を開く。ホームの「暗記・復習」にも入口を追加した。

## ファイル

- `app/term-drill.html`：開始条件・問題・候補入力・解答後・結果の画面。
- `app/term-drill.js`：用語集読込、読み検索、明示別名の同一視、候補選択、採点、連続出題、保存・再開・解き直し。
- `app/term-questions.js`：既存の生理学20問。ID・正答・文面は今回変更しない。
- `app/term-questions-anatomy.js`：追加の解剖学20問。
- `app/term-questions-kinesiology.js`：追加の運動学20問。
- 新しい問いは医学的根拠と正答キー・許容別名を明示して追加する。用語集の定義から無検品で全問を生成する方式にはしていない。
- `app/term-drill.css`：共有色トークンを使ったスマホ・PC・暗色表示。
- `app/index.html`：入口のリンクだけを追加。
- `app/sw.js`：ドリルの画面・データJSをSHELLへ登録。今回の科目追加でv11からv12へ更新。
- `tools/term_input_check.cjs`：独立したブラウザーでの機能・表示検証。

既存データファイルの変更はない。ブランチは `feature/term-input-practice`。更新済みの `origin/main`（`773d8e2`）を基点とし、旧試作コミット1件だけを移植して拡張した。旧履歴のmergeや、撤回された教科書同梱・自動読込機能の復活はしていない。本体フォルダーと旧試作フォルダーは変更していない。

## 医学的根拠

- 搭載済み `content/glossary/glossary.json` の用語キーと読みを利用し、本文を変更しない。
- [NIH / NIGMS: Circadian Rhythms](https://www.nigms.nih.gov/education/fact-sheets/Pages/circadian-rhythms)、[OpenStax Anatomy and Physiology 2e](https://openstax.org/books/anatomy-and-physiology-2e/pages/1-introduction)、[東京大学医学部附属病院 循環器内科](https://cardiovasc.m.u-tokyo.ac.jp/consultation/diseases/irregular_pulse)の該当箇所を参照。各問に直接リンクを付けた。
- 2026-11-11、作成担当とは別の担当が20問、許容別名18件、正答キー、出典16URLを独立照合した。医学的文面の具体的な修正指摘はなかった。すべての表記ゆれを網羅する保証はない。
- 科目拡充では、解剖学20問（別名9件・出典16URL）と運動学20問（別名22件・掲載出典12URL）を、それぞれ作成担当とは別の担当が独立照合した。全60問の掲載出典は計44URL、明示別名は計49件。具体的な医学的修正指摘はなかった。

## 検証

過去の例題検査は `用語入力確認/`、生理学20問版の195項目合格は `用語入力連続確認/` に保持する。3科目版は `用語入力3科目確認/` に結果と画像22枚を保存した。502項目すべて合格、JS例外・予期しないconsoleエラーは0件。検査対象は、360/390/412/1280px・暗色、候補のタップとキーボード、模擬IME、全問・別名採点、科目選択・混合出題、全問選択、復習、旧記録からの再開、保存不可・不整合データ、既存成績不変更、本体過去問の採点と誤り理由。

その後、用語集のHTTP応答が成功でも内容が不正な場合に、科目変更やフォーム送信から練習を開始できないよう、データ準備完了のガードを追加した。この変更は追加11項目に合格。4種の科目切替・送信抑止・記録未作成と、正常データ再読込後の開始・採点・次問を差分検証した。`report-invalid-schema.json` と追加画像1枚に記録し、基礎502項目の結果は保持している。両検査ともJS例外・予期しないconsoleエラー0件。

検証はローカルファイルをブラウザーのリクエストへ直接返す方式で行い、API保存も模擬応答とした。実際の学習記録は読み書きしていない。実機Androidのソフトキーボード・IME、スクリーンリーダー、実ネット配信とService Workerの圏外動作は未確認。
