# 誤答の「作られ方」ラベル付け（作業療法士国家試験の過去問）

## 目的
国家試験の誤答選択肢は、創作された語ではなく「実在する別のもの」で作られる。
誤答1個ごとに「どうやって誤りにしてあるか（型）」「何をずらしたか（軸）」「その内容は本来どこのものか（本来）」を付ける。
受験生が「この選択肢は○○期の話だから×」「これは失語の検査だから×」と見抜けるようにするためのデータ。

## 入力
`in/bNN.json` は問題の配列。各問題に 問題文・選択肢（番号→文）・正答（番号の配列）・誤り理由（誤答の番号→照合済みの解説）がある。
ラベルを付けるのは **「誤り理由」にキーがある選択肢だけ**（＝誤答）。
問題文が「誤っているのはどれか」「適切でないのはどれか」型のときは、誤り理由のキーが正答（＝内容が誤っている・不適切な文）に付いていることが多い。その場合はその文が「どう誤りにしてあるか」で普通に型を付ける。キーの付いた文の内容が正しい場合だけ 型="正しい内容（否定形の問題）" を付け、軸・本来は空にする。

## 付け方（必ず1問ずつ読んで判断する。キーワード一致やスクリプトでの機械判定は禁止）
誤り理由は照合済みの根拠として使う。医学的な内容を自分の推測で上書きしない。

### 型（1つ選ぶ。上から順に当てはまるものを優先）
- `反対にする` … 方向・増減・有無・順序が逆（例: 散大→縮小、増加→減少、受容的に→指示的に）
- `時期・段階のずれ` … 同じ疾患・同じ対象の中で、別の時期・病期・回復段階・重症度・レベル・年齢の内容を持ってきた（例: 回復期前期の目標を聞かれて維持期の目標。亜急性期に高負荷の活動。時期尚早）
- `別のものと入れ替え` … 同じ仲間の別のもの（別の疾患・別の評価法・別の技法・別の人物・別の制度・別の部位）の名前や特徴を持ってきた（例: うつ病の尺度を聞かれて認知症の尺度）
- `言い過ぎ・限定` … のみ・必ず・すべて・一切、程度の誇張や限定で誤りにした
- `原則に反する対応` … 時期に関係なく、その疾患・場面での関わり方の原則に反する（例: 妄想を説得・否定する、叱責する、できない約束をする、依存を助長する、禁忌）
- `優先度が低い` … 内容は正しく問いとも関係があるが、優先順位・重要度で落とす（「最も優先」「まず確認」型の問題で、誤り理由が「優先度が低い」「〜が先」としか言っていないもの。別の時期なら正しいと言えるなら 時期・段階のずれ）
- `問いと無関係` … 実在し正しい内容だが、問われていることと関係がない・含まれない（入れ替え元がはっきりしないとき）
- `数値・記号` … 数値の計算違い、図や記号の選択など、上の型に当てはめる意味がないもの
- `正しい内容（否定形の問題）` … 上記のとおり
- `その他` … どれにも当てはまらない

「時期・段階のずれ」と「原則に反する対応」で迷ったら: 別の時期なら正しくなる内容 → 時期・段階のずれ。どの時期でも不適切 → 原則に反する対応。
「別のものと入れ替え」と「問いと無関係」で迷ったら: 「それは○○のものだ」と持ち主を言える → 別のものと入れ替え。

### 軸（何がずれている／入れ替わっているか。1つ選ぶ。該当なしは空文字）
`時期・病期` / `重症度・段階・レベル` / `年齢・発達段階` / `疾患・病型` / `症状・所見` / `評価法の対象`（何を・誰を評価する道具か） / `評価法の中身`（項目・方法・採点・形式） / `治療法・技法・プログラム` / `活動・作業種目` / `関わり方・態度` / `目標・目的` / `人物・理論` / `制度・法律・職種・施設` / `部位・構造・機能` / `筋の作用・神経支配` / `機序・原因・分類` / `検査所見・画像` / `薬剤` / `用具・装具・自助具` / `動作・方法・手順` / `数値・量` / `その他`

### 本来（25字以内。言えるときだけ。言えなければ空文字）
その誤答の内容が本来あてはまる先。誤り理由に書かれている範囲で書く。
例: 「維持期の目標」「急性期の症状」「認知症の行動・心理症状の尺度」「失語症の検査」「躁状態への対応」「統合失調症の陰性症状尺度」
誤り理由に書かれていないことを推測で足さない（評価法の対象のように誤り理由に明記されているものはそのまま使う）。

### 疑義（ふつうは空文字）
誤り理由そのものに事実の誤り・誤植の疑いがあると気づいたときだけ、40字以内で書く（例: 「GBSスケールは認知症の尺度のはず」）。直さない。ラベルは誤り理由のまま付け、確信は 低 にする。

### 確信
`高` または `低`（型か軸で迷ったら 低）

## 出力
`out/bNN.json` に次の形の配列を書く（入力の誤り理由のキーと1対1。抜け・重複なし）。
```json
[{"id":"50-am-044","n":"2","型":"時期・段階のずれ","軸":"時期・病期","本来":"維持期の目標","確信":"高","疑義":""}]
```
型・軸の値は上の一覧の文字列をそのまま使う（表記を変えない）。
書き終えたら、入力の（id, 誤答番号）の集合と出力が一致することを短い Python で確かめる（確かめるだけ。ラベルの判定には使わない）。
