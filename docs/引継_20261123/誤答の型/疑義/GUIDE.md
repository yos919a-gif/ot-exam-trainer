# 誤り理由の疑義の照合

作業療法士国家試験の過去問アプリの「誤り理由」（誤答選択肢がなぜ誤りかの短い解説）に、事実の誤り・誤植・根拠不足の疑いが出たものを、信頼できる資料で確かめる。

## 入力
`in/X.json` は問題の配列。各問題に 問題文・選択肢・正答（厚労省の公式正答。**正答は変えない・疑わない**）・誤り理由（番号→現在の解説）・疑義（番号→疑いの内容）がある。
確かめるのは「疑義」にキーがある選択肢の誤り理由だけ。

## やること
疑義ごとに、Web で資料を探して確かめる。
- 優先する資料: 法令・告示・通知（厚生労働省、e-Gov）、学会・職能団体の公式資料やガイドライン、検査・尺度の原著や開発者の資料、大学・公的機関の資料、医学書院・南江堂・医歯薬などの標準的な教科書の内容が確認できるページ、査読論文。
- 使わない: 国試対策本『必修ポイント』（誤植が多い）。個人ブログや国試解説サイトだけを根拠にしない（補助としては可、その場合は2つ以上の独立した資料で一致を確かめる）。
- 自分の記憶だけで判定しない。資料で確かめられなければ「判断できず」にする。
- 疑義の指摘のほうが間違っていることもある。先入観なく確かめる。
- 「〜とする見方もあるが、正答の方が確実」のように根拠を示していない誤り理由は、その選択肢がなぜ誤り（または正答より劣る）とされるのかを資料で確かめて書き直す。確かめられなければ「判断できず」。

## 出力 `out/X.json`
```json
[{"id":"61-pm-003","n":"1",
  "判定":"誤り理由は誤り",
  "修正案":"ペグ法は視覚イメージを使う記憶術（記憶障害の方略）→ 半側空間無視への介入ではない",
  "根拠":[{"資料":"資料名（発行元）","url":"https://...","内容":"その資料に書かれていること（要旨、60字以内）"}],
  "確信":"高",
  "メモ":""}]
```
- 判定は `誤り理由は誤り` / `誤り理由は正しい` / `誤り理由は根拠不足（書き直し可）` / `判断できず` のどれか。
- 修正案は、判定が「誤り」「根拠不足（書き直し可）」のときだけ書く。現在の誤り理由の文体（「事実 → だから誤り」の1行、70字以内、です・ます無し）に合わせる。それ以外は空文字。
- 根拠は実際に開いて確かめた資料だけ。URL を作らない。
- 確信は `高`（一次資料または標準的資料2つ以上で一致）/ `低`。
- 入力の疑義のキー（正答キーは無い）と1対1。

## 触ってよいもの
読み: `in/X.json` とこの GUIDE.md。書き: `out/X.json` だけ。リポジトリの他のファイル・git には触らない。Web 検索では問題文をそのまま貼るのは構わないが、利用者の名前など個人の情報は送らない。

## 報告
判定ごとの件数と、判断できなかったものの id・理由を日本語で短く。
