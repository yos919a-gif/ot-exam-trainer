## 1. 目的（ユーザーの狙い）

過去問2,400問（第50〜61回）から「国試の誤答がどう作られているか」を取り出し、**同じ作り方でオリジナルの模試を作れるようにする**。
そのために (1) 試験委員と出題範囲、(2) 正答と誤答の選択肢の作られ方、を分析した。次は (3) 単語ごとの分類。

## 2. ユーザーが示した国試の見方（設計の前提。変えない）

1. **創作された名前は出ない**（例「外側上腕多裂筋」のような語は無い）。誤答はすべて実在の語。模試の選択肢も実在の語だけで作る。
2. **狙われるのは同じカテゴリーの別単語**。例: 統合失調症の治療で、維持期の話なのに要安静期の内容を言っているから×。
3. **評価法は対象の違う道具を混ぜる**。例: うつ病の評価・人格の評価・認知症の評価を同じ問題に並べる。
4. 筋の問題の誤答の作り方の例: 反対の作用／別の部位の作用／別の関節との混同／名前が似ている。
5. **『必修ポイント』は誤植が多い**。根拠にしない。基礎医学・臨床医学の2冊は誤植の確定が済んでいる。**残り2冊（基礎OT学 b044・障害別OT治療学 b047）の誤植判定はメインPC側で行う**（ユーザー決定。こちらでは未着手）。
6. **モデルの使い分け**: 「速度には速度、正確さには正確さ」。判断の要らない量の作業は下位モデルかスクリプト、医学的な正しさ・裁定・最終確認は上位モデル。

## 4. 誤答ラベルの形と定義

`誤答ラベル_全件.json` は配列。1要素＝誤り理由が付いている選択肢1個（＝ `explanations.json` の `c` のキーと1対1。8,565個で抜け・重複なしを確認済み）。

```json
{"id":"50-am-044","n":"2","型":"時期・段階のずれ","軸":"時期・病期","本来":"維持期の目標","確信":"高","疑義":"","版":"試し分"}
```

- `n` 選択肢の番号（文字列）
- `型` どう誤りにしてあるか（1つ）
- `軸` 何をずらした／入れ替えたか（1つ、空あり）
- `本来` その内容が本来あてはまる先（25字以内の自由記述、空あり）
- `確信` 高／低
- `疑義` 誤り理由そのものに誤りの疑いがあるときの指摘（ふつう空）
- `版` 試し分／全件／全件(補完)

**型**（定義の全文は `full/GUIDE.md`）: 反対にする／時期・段階のずれ／別のものと入れ替え／言い過ぎ・限定／原則に反する対応／優先度が低い／問いと無関係／数値・記号／正しい内容（否定形の問題）／その他

**軸**: 時期・病期／重症度・段階・レベル／年齢・発達段階／疾患・病型／症状・所見／評価法の対象／評価法の中身／治療法・技法・プログラム／活動・作業種目／関わり方・態度／目標・目的／人物・理論／制度・法律・職種・施設／部位・構造・機能／筋の作用・神経支配／機序・原因・分類／検査所見・画像／薬剤／用具・装具・自助具／動作・方法・手順／数値・量／その他

### 作り方と精度（正直な範囲）

- 読み手は上位モデル（Fable）81エージェント（試し分9＋全件72）。1束 約105〜118個。合計 約475万トークン。機械判定は禁止し、1問ずつ読ませた。
- **2人読み・照合はしていない**（読み手1人）。メインPCの基準（2人が独立に読む→割れを裁定）より弱い。確信 低 は見直し対象。
- Claude 本人が見たのは実例数十件と集計だけ。全件の見直しはしていない。
- 迷いが多い境目: 「反対にする」⇔「別のものと入れ替え」（交感／副交感、拮抗筋）、「時期・段階のずれ」⇔「原則に反する対応」（精神の導入期の対応）。束ごとに寄せ方が少し違う。
- 図の問題（MMT・ROM・画像選択）は図を見ていないので型が粗い（数値・記号／入れ替え、確信 低）。

### 罠・注意

1. **試し分（精神障害作業療法166問＋評価法の問題105問、996個）は旧版の指示書**。型「優先度が低い」が無く、該当は「その他」「問いと無関係」に散っている。追加した軸（筋の作用・神経支配 など）も使っていない。`版` が 試し分 の行で判別できる。そろえるなら試し分だけ最終版で読み直す。
2. **否定形の問題**（誤っている・適切でないのはどれか）は、誤り理由のキーが正答（＝不適切な文）に付いていることが多い。その行の型は「その不適切な文の作られ方」。キーの文が正しい内容のときだけ「正しい内容（否定形の問題）」。
3. `61-am-043` の4個は読み手の出力から漏れたので Claude が補った（`版`: 全件(補完)）。
4. 採点方式「いずれか1つで正解」の問題（57-am-100、61-pm-075 など）は公式の複数正答。読み手が「正答に疑い」と書くことがあるが、データの誤りではない。
5. PR #3 で誤り理由を直した17個は、**ラベルの `本来` が古い誤り理由にもとづいたまま**。付け直しが要る（対象は `疑義/適用した修正.json`）。
6. 採点除外など誤り理由の無い26問はラベルの対象外。

### 7-1. 単語ごとの分類（ユーザーと合意済みの次の工程）

今あるのは「誤答の選択肢ごとの作られ方」で、**単語ごとの分類はまだ無い**。

現状（用語の形をした選択肢の語 3,514語。短い名詞だけを数えた目安）:

- `本来` は分類ではなく「その問題で問われた面の特徴」が混じる（くも膜下出血 → 脳動脈瘤の破裂が主因／脳槽に高吸収域／突然の激しい頭痛）

模試づくりに要る形（語ごと）:
- **カテゴリー**（属する仲間。例 VPTA → 高次脳機能の検査 → 視知覚・失認）
- **同じ仲間の語**（入れ替えの相手。例 SLTA・BIT・SPTA・RBMT）
- **特徴**（問われる面ごとの内容。対象・下位項目・採点、作用・支配、時期ごとの目標 など）

材料: このラベル（本来・軸）、用語集7,070語の意味と科目、**メインPCの語の台帳 `data/knowledge/kg.jsonl`（⊂ ∈ ＝・起始/停止/支配・並列・順序）**。解剖・生理のカテゴリーと仲間は台帳から取れるはず。評価法は 4. の対象分類（Claude が手で作った20分類。このセッション内だけでファイルは無い。作り直す）。

進め方の案（モデルの使い分け）:
1. スクリプト: 語ごとに、今ある 本来・軸・用語集の意味・台帳の関係を集める。
2. 下位モデル: `本来` の書き方のゆれを語ごとに1つにまとめる。
3. 上位モデル: カテゴリーの体系を決め、境目の語を裁定する。
4. 時期・段階のずれ用に、疾患×時期の表（統合失調症の要安静期・亜急性期・回復期前期・後期・維持期ごとの目標・活動・対応、発達月齢、脊髄損傷のレベル、筋ジストロフィーのステージ など）を別に作る。
